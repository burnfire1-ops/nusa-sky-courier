# Nusa Sky Courier

A 3D courier flight game set in a volcanic archipelago at dusk. Fly a small cargo plane between three islands, thread golden rings, land precisely on short runways, and build your courier rank — PEMULA to LEGENDA — one delivery at a time.

- **Fly:** keyboard + mouse, lift scales with speed squared, stall below 55 kts, wind and gusts, fuel burns with throttle.
- **Deliver:** three islands, three economies, three mission archetypes — Ring Run, Precision Delivery, Storm Run.
- **Earn:** KR currency, a hangar shop with three upgrades, and a landing Rank (A/B/C/S) after every flight.

Play it: `node serve.ts`, then open http://localhost:8080. No build step, no network — Three.js r187 is vendored under `game/vendor/`.
